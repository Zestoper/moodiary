## 1. axios 인터셉터 — `api/axios.js`

```javascript
const instance = axios.create({
  baseURL: process.env.REACT_APP_API_URL || 'http://localhost:8000',
});

// 요청 인터셉터: 모든 요청에 JWT 토큰 자동 추가
instance.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// 응답 인터셉터: 401이면 토큰 삭제 + 로그인으로 리다이렉트
instance.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401 && !error.config.url.includes('/api/auth/login')) {
      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);
```

**핵심 포인트**
- 모든 API 함수 파일에서 `import api from './axios'`로 이 인스턴스를 씁니다.
- `/api/auth/login` URL은 401 체크에서 제외합니다. 비밀번호가 틀렸을 때의 401도 리다이렉트하면 안 되기 때문입니다.
- `Promise.reject(error)` — 에러를 다시 던져야 각 호출부에서 `catch`로 잡을 수 있습니다.

## 2. AuthContext — `context/AuthContext.jsx`

```javascript
export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);
  const [token, setToken] = useState(localStorage.getItem('token'));
  // 초기값으로 localStorage의 토큰을 읽어 로그인 상태 유지

  const login = (userData, accessToken) => {
    setUser(userData);
    setToken(accessToken);
    localStorage.setItem('token', accessToken);
  };

  const logout = () => {
    setUser(null);
    setToken(null);
    localStorage.removeItem('token');
  };

  const refreshUser = async () => {
    const res = await api.get('/api/auth/me');
    setUser(res.data);  // 서버에서 최신 크레딧·관리자 여부 반영
  };

  return (
    <AuthContext.Provider value={{ user, token, login, logout, refreshUser }}>
      {children}
    </AuthContext.Provider>
  );
}
```

**핵심 포인트**
- `AuthProvider`로 `App.js`에서 전체를 감싸면, 모든 컴포넌트에서 `useAuth()`로 user/token에 접근합니다.
- 새로고침 후에도 `localStorage.getItem('token')`으로 토큰 초기값을 복원합니다.
- `refreshUser()`: 결제 후 크레딧 수가 바뀌면 이 함수를 호출해 UI를 갱신합니다.

## 3. SSE 스트리밍 구현 — `pages/ChatPage.jsx`

```javascript
const handleSend = async () => {
  // 1. 낙관적 업데이트: 화면에 먼저 추가
  const tempId = Date.now();
  setMessages((prev) => [
    ...prev,
    { id: `temp-u-${tempId}`, role: 'user', content: myMessage },
    { id: `temp-a-${tempId}`, role: 'assistant', content: '' },  // 빈 AI 말풍선
  ]);

  // 2. SSE fetch (axios 사용 불가 → fetch 직접 사용)
  const response = await fetch('/api/chat/stream', {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${token}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({ content: myMessage, persona, diary_id: diaryId }),
  });

  // 3. ReadableStream 청크 단위 읽기
  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let buffer = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    buffer += decoder.decode(value, { stream: true });
    const lines = buffer.split('\n');
    buffer = lines.pop();  // 잘린 줄은 다음 청크와 합치기 위해 보관

    for (const line of lines) {
      if (!line.startsWith('data: ')) continue;
      const data = JSON.parse(line.slice(6));

      if (data.type === 'chunk') {
        // AI 말풍선 마지막에 텍스트 이어붙이기
        setMessages((prev) => {
          const msgs = [...prev];
          const last = msgs[msgs.length - 1];
          msgs[msgs.length - 1] = { ...last, content: last.content + data.content };
          return msgs;
        });
      } else if (data.type === 'done') {
        // 임시 ID → 실제 DB ID 교체
        setMessages((prev) => {
          const msgs = [...prev];
          msgs[msgs.length - 2] = { ...msgs[msgs.length - 2], id: data.user_msg_id };
          msgs[msgs.length - 1] = { ...msgs[msgs.length - 1], id: data.ai_msg_id };
          return msgs;
        });
      }
    }
  }
};
```

**핵심 포인트**
- `buffer += decoder.decode(value, { stream: true })` — `{stream: true}`가 없으면 멀티바이트 한글 문자가 청크 경계에서 깨질 수 있습니다.
- `lines.pop()` — 마지막 줄은 아직 완성되지 않은 SSE 이벤트일 수 있어 다음 청크와 합칩니다.
- `setMessages`에서 함수형 업데이트(`(prev) => ...`) — 클로저 문제로 stale state가 되지 않도록 합니다.

## 4. debounce 초안 자동저장 — `pages/DiaryPage.jsx`

```javascript
const draftTimerRef = useRef(null);

useEffect(() => {
  if (!showForm) return;
  clearTimeout(draftTimerRef.current);  // 이전 타이머 취소
  draftTimerRef.current = setTimeout(() => {
    if (title || content) {
      localStorage.setItem('diary_draft', JSON.stringify({ title, content }));
    }
  }, 500);  // 타이핑 멈춘 후 500ms 후 저장
  return () => clearTimeout(draftTimerRef.current);  // cleanup
}, [title, content, showForm]);

// 폼 열릴 때 초안 복원
useEffect(() => {
  if (!showForm) return;
  const saved = localStorage.getItem('diary_draft');
  if (!saved) return;
  const { title: t, content: c } = JSON.parse(saved);
  if (t || c) { setTitle(t || ''); setContent(c || ''); }
}, [showForm]);
```

**핵심 포인트**
- `useRef`로 타이머 ID를 보관 → `clearTimeout`으로 이전 타이머를 취소합니다.
- 타이핑할 때마다 저장하는 대신, 멈춘 후 500ms 후 저장합니다. (성능 최적화)
- `return () => clearTimeout(...)` — 컴포넌트 언마운트 또는 의존성 변경 시 cleanup 함수가 실행됩니다.

## 5. 날씨 자동 기록 — `pages/DiaryPage.jsx`

```javascript
const fetchWeather = () => {
  if (!navigator.geolocation) return;
  navigator.geolocation.getCurrentPosition(
    async ({ coords }) => {
      const url = `https://api.open-meteo.com/v1/forecast`
        + `?latitude=${coords.latitude}&longitude=${coords.longitude}`
        + `&current=temperature_2m,weather_code`;
      const res = await fetch(url);
      const json = await res.json();
      const code = json.current.weather_code;
      const temp = Math.round(json.current.temperature_2m);
      setWeatherInfo({ code, temperature: temp, ...(WMO[code] || { emoji: '🌡️', text: '날씨' }) });
    },
    () => {},          // 위치 권한 거부 → 무시
    { timeout: 5000 }
  );
};
```

**핵심 포인트**
- `navigator.geolocation.getCurrentPosition()` — 브라우저 내장 위치 API. 사용자 허용 필요합니다.
- Open-Meteo는 무료이고 API 키가 불필요합니다.
- `...(WMO[code] || {...})` — 스프레드로 `{ emoji, text }` 속성을 weatherInfo에 합칩니다.
- 날씨 실패 + 위치 거부 모두 무시 → 일기 작성은 항상 가능합니다.

## 6. 검색 필터 (실시간) — `pages/DiaryPage.jsx`

```javascript
const filteredDiaries = diaries.filter((d) => {
  if (!search.trim()) return true;
  const q = search.toLowerCase();
  return (
    d.title.toLowerCase().includes(q) ||
    d.content.toLowerCase().includes(q) ||
    (d.emotion_tags && d.emotion_tags.toLowerCase().includes(q))
  );
});
```

**핵심 포인트**
- API 호출 없이 이미 불러온 `diaries` 배열을 프론트에서 직접 필터링합니다.
- `toLowerCase()` — 대소문자 무시 검색
- `search` state가 바뀔 때마다 `filteredDiaries`가 재계산됩니다 (파생 상태, useEffect 불필요).

## 7. XSS 방지 PDF 내보내기 — `pages/DiaryPage.jsx`

```javascript
const escapeHtml = (str) =>
  String(str)
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;');

const html = `<h1>${escapeHtml(diary.title)}</h1>
              <p>${escapeHtml(diary.content).replace(/\n/g, '<br>')}</p>`;

const blob = new Blob([html], { type: 'text/html; charset=utf-8' });
const blobUrl = URL.createObjectURL(blob);
window.open(blobUrl, '_blank');
setTimeout(() => URL.revokeObjectURL(blobUrl), 5000);
```

**핵심 포인트**
- `escapeHtml()` — 일기 내용에 `<script>` 같은 HTML이 있어도 태그로 해석되지 않게 escape합니다.
- `Blob` → `createObjectURL` → `window.open` → `print()` 자동 실행의 PDF 저장 흐름입니다.
- `revokeObjectURL(blobUrl)` — 5초 후 브라우저 메모리에서 임시 URL을 해제합니다.

## 8. 페르소나 localStorage 동기화 — `pages/DiaryPage.jsx`

```javascript
const [persona, setPersona] = useState(() => localStorage.getItem('ai_persona') || 'friend');

useEffect(() => {
  localStorage.setItem('ai_persona', persona);
}, [persona]);

// ChatPage에서 읽기
const persona = localStorage.getItem('ai_persona') || 'friend';
```

**핵심 포인트**
- `useState(() => ...)` — lazy initializer. 초기 렌더링에 한 번만 실행됩니다.
- DiaryPage에서 선택한 페르소나를 ChatPage가 localStorage로 공유합니다. Context를 쓰지 않아도 되는 단순한 공유 방법입니다.
- 버튼 클릭 시 `setPersona` + `localStorage.setItem` 모두 호출해 즉시 반영합니다.
