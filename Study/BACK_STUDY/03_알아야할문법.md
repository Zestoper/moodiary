## 1. 타입 힌트 (Type Hints)

```python
from typing import Optional, List

def decode_access_token(token: str) -> Optional[str]:
    ...

def get_diaries(...) -> List[DiaryResponse]:
    ...
```

- `str`, `int`, `bool`, `dict`, `list` 등 기본 타입 명시
- `Optional[str]` = `str | None` — 값이 없을 수 있음
- `List[DiaryResponse]` — DiaryResponse 객체 리스트
- FastAPI가 타입 힌트를 보고 자동 직렬화/역직렬화합니다.

## 2. 데코레이터 (Decorator)

```python
@router.get("/", response_model=List[DiaryResponse])
def get_diaries(db: Session = Depends(get_db)):
    ...

@router.post("/{diary_id}/solution", response_model=DiaryResponse)
def get_solution(diary_id: int, ...):
    ...
```

- `@router.get/post/put/patch/delete("/경로")` — HTTP 메서드와 URL을 함수에 연결합니다.
- `response_model` — 반환값을 지정한 스키마로 자동 변환합니다. 비밀번호 같은 필드를 제외할 수 있습니다.
- `status_code=201` — 성공 응답 코드를 200이 아닌 201(Created)로 지정합니다.

## 3. Pydantic BaseModel과 Field

```python
from pydantic import BaseModel, EmailStr, Field

class UserRegister(BaseModel):
    email: EmailStr                      # 이메일 형식 자동 검증
    username: str = Field(min_length=1, max_length=20)
    password: str = Field(min_length=6)  # 6자 미만이면 422 에러
```

- `BaseModel` 상속 → JSON 파싱 + 유효성 검사 자동 처리
- `Field(min_length=...)` — 최소 길이 제약
- `EmailStr` — `@`와 도메인 포함 이메일 형식 검증
- `Optional[str] = None` — 없어도 되는 필드

## 4. SQLAlchemy 쿼리 패턴

```python
# 단건 조회
diary = db.query(Diary).filter(
    Diary.id == diary_id,
    Diary.user_id == current_user.id  # AND 조건
).first()

# 복수 조회 + 정렬
diaries = db.query(Diary)\
    .filter(Diary.user_id == current_user.id)\
    .order_by(Diary.created_at.desc())\
    .all()

# 집계
total = db.query(func.count(User.id)).scalar()
```

- `.filter(조건1, 조건2)` — AND 조건
- `.first()` — 첫 번째 결과. 없으면 `None`
- `.all()` — 전체 결과 리스트
- `.scalar()` — 단일 값(숫자) 반환
- `func.count()`, `func.sum()` — SQL 집계 함수

## 5. 예외 처리

```python
# FastAPI HTTP 에러
raise HTTPException(status_code=404, detail="일기를 찾을 수 없습니다")
raise HTTPException(status_code=402, detail={"message": "크레딧이 부족합니다", "feature": "solution"})

# try/except로 AI 실패 무시
try:
    result = analyze_emotion(body.content)
except Exception:
    pass  # 실패해도 일기 저장은 진행
```

- `HTTPException` — FastAPI가 지정한 status_code의 JSON 응답을 자동으로 반환합니다.
- `detail`은 문자열 또는 dict 모두 가능합니다.
- `except Exception: pass` — 외부 API 실패가 핵심 기능을 막지 않도록 격리합니다.

## 7. 딕셔너리 `.get()` 메서드

```python
result = json.loads(raw)
emotion_tags = result.get("emotion_tags")    # 없으면 None
emotion_score = result.get("emotion_score")  # 없으면 None

FREE_LIMITS.get("solution", 0)  # 없으면 기본값 0
```

- `dict["key"]` — 키가 없으면 `KeyError` 발생
- `dict.get("key")` — 키가 없으면 `None` 반환 (안전)
- `dict.get("key", 기본값)` — 키가 없으면 기본값 반환

## 8. 정규식 (`re` 모듈)

```python
import re

# 한자·키릴 문자를 공백으로 대체
cleaned = re.sub(r'[一-鿿Ѐ-ӿ]', ' ', text)

# 연속 공백 정리
result = re.sub(r' {2,}', ' ', cleaned)

# <think>...</think> 블록 제거 (DOTALL: 줄바꿈도 매칭)
filtered = re.sub(r'<think>.*?</think>', '', text, flags=re.DOTALL)
```

- `re.sub(패턴, 대체문자, 문자열)` — 패턴에 맞는 부분을 모두 대체합니다.
- `[범위]` — 유니코드 범위 문자 클래스
- `.*?` — 최소 일치(non-greedy)
- `re.DOTALL` — `.`이 `\n`까지 매칭하게 합니다.

## 10. 제너레이터 함수 (`yield`)

```python
def get_db():
    db = SessionLocal()
    try:
        yield db    # 여기서 멈추고 db를 반환
    finally:
        db.close()  # 재개 후 실행

def generate():       # SSE 스트리밍 제너레이터
    for chunk in stream:
        yield f"data: {json.dumps(chunk)}\n\n"
```

- 일반 함수: `return`으로 값을 반환하면 함수 종료
- 제너레이터: `yield`로 값을 반환하고 함수는 그 지점에서 일시정지
- `for item in generator():` 로 순서대로 값을 꺼냅니다.

## 11. `startup` 이벤트

```python
@app.on_event("startup")
def migrate_db():
    Base.metadata.create_all(bind=engine)
    with engine.connect() as conn:
        conn.execute(text("ALTER TABLE users ADD COLUMN IF NOT EXISTS is_admin BOOLEAN NOT NULL DEFAULT FALSE"))
        conn.commit()
```

- FastAPI 앱이 시작될 때 한 번 실행됩니다.
- `create_all()` — 정의된 ORM 모델의 테이블이 없으면 생성합니다(있으면 스킵).
- `IF NOT EXISTS` — 컬럼이 이미 있어도 에러 없이 스킵합니다.

## 12. 환경변수 읽기 — Pydantic Settings

```python
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    DATABASE_URL: str
    SECRET_KEY: str
    GROQ_API_KEY: str
    YOUTUBE_API_KEY: str = ""  # 기본값: 빈 문자열 (없어도 됨)

    class Config:
        env_file = ".env"

settings = Settings()
```

- `.env` 파일에서 자동으로 환경변수를 읽어옵니다.
- 타입 힌트로 자동 변환 (`str`, `int`, `bool`).
- 필수 변수가 없으면 앱 시작 시 에러가 발생합니다.
