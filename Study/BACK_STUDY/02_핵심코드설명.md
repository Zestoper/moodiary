# 백엔드 핵심 코드 설명 — Moodiary 기준

---

## 1. DB 세션 의존성 — `core/database.py`

```python
def get_db():
    db = SessionLocal()
    try:
        yield db       # 라우터에 세션 전달
    finally:
        db.close()     # 요청 끝나면 항상 닫힘
```

**흐름 설명**
1. 요청이 들어오면 FastAPI가 `Depends(get_db)`를 감지해 `get_db()`를 실행합니다.
2. `yield db`에서 라우터 함수에 세션을 넘겨주고 일시 정지합니다.
3. 라우터가 실행 완료(또는 예외 발생)되면 `finally: db.close()`로 항상 세션을 닫습니다.

`yield`가 없으면 요청이 끝나도 세션이 닫히지 않아 DB 커넥션이 고갈됩니다.

## 2. 인증 의존성 체인 — `routers/auth.py`

```python
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/auth/login")

def get_current_user(
    token: str = Depends(oauth2_scheme),  # 헤더에서 토큰 자동 추출
    db: Session = Depends(get_db)
) -> User:
    user_id = decode_access_token(token)
    if user_id is None:
        raise HTTPException(status_code=401, ...)
    user = db.query(User).filter(User.id == int(user_id)).first()
    if user is None:
        raise HTTPException(status_code=404, ...)
    return user
```

**흐름 설명**
- `OAuth2PasswordBearer`: 요청 헤더 `Authorization: Bearer <토큰>`에서 토큰 문자열만 추출합니다.
- `decode_access_token()`: 토큰을 해석해 `sub`(유저 ID)를 꺼냅니다. 위조/만료 시 `None` 반환.
- 라우터에서 `current_user: User = Depends(get_current_user)`로 선언하면 이 로직이 자동 실행됩니다.

Depends 체인: `get_current_user` → `oauth2_scheme` + `get_db` → `decode_access_token`

## 3. JWT 생성과 검증 — `core/security.py`

```python
def create_access_token(data: dict) -> str:
    to_encode = data.copy()
    expire = datetime.utcnow() + timedelta(minutes=settings.ACCESS_TOKEN_EXPIRE_MINUTES)
    to_encode.update({"exp": expire})
    return jwt.encode(to_encode, settings.SECRET_KEY, algorithm=settings.ALGORITHM)

def decode_access_token(token: str) -> Optional[str]:
    try:
        payload = jwt.decode(token, settings.SECRET_KEY, algorithms=[settings.ALGORITHM])
        return payload.get("sub")
    except JWTError:
        return None
```

- **인코딩**: `{"sub": "유저ID", "exp": 만료시각}` 형태의 dict → JWT 문자열
- **디코딩**: JWT 문자열 → dict. 만료/위조 시 `JWTError` 발생 → `None` 반환
- `exp` 필드는 `jwt.decode()`가 자동으로 만료 검증합니다.

## 4. 쿼터 & 크레딧 차감 — `services/quota.py`

```python
FREE_LIMITS = {"solution": 3, "consult": 5, "monthly_report": 1}

def check_and_consume(db, user, feature):
    now = datetime.now()
    quota = db.query(UsageQuota).filter(
        UsageQuota.user_id == user.id,
        UsageQuota.feature == feature,
        UsageQuota.year == now.year,
        UsageQuota.month == now.month,
    ).first()

    used = quota.count if quota else 0

    if used < FREE_LIMITS[feature]:
        # 무료 한도 남음 → count +1
        ...
        db.commit()
        return

    if user.credits < 1:
        raise HTTPException(status_code=402, ...)  # 결제 필요

    user.credits -= 1  # 크레딧 차감
    ...
    db.commit()
```

**로직 흐름**
1. 이번 달 해당 기능의 사용 횟수를 조회합니다.
2. 무료 한도(솔루션 3회, 상담 5회, 리포트 1회) 미만이면 count +1 후 반환합니다.
3. 한도 초과 + 크레딧 있음 → 크레딧 1 차감합니다.
4. 한도 초과 + 크레딧 없음 → HTTP 402 에러를 던집니다.

## 5. SSE 스트리밍 응답 — `routers/chat.py`

```python
@router.post("/stream")
def stream_message(body, db, current_user):
    # 유저 메시지를 먼저 DB 저장
    user_msg = ChatMessage(user_id=..., role="user", content=body.content, diary_id=body.diary_id)
    db.add(user_msg); db.commit(); db.refresh(user_msg)
    user_msg_id = user_msg.id  # 제너레이터 클로저에서 사용할 값 미리 저장

    def generate():
        full_response = []
        for chunk_text in chat_with_ai_stream(messages_for_ai, diary_context, body.persona):
            full_response.append(chunk_text)
            yield f"data: {json.dumps({'type': 'chunk', 'content': chunk_text})}\n\n"

        # 스트리밍 완료 후 새 세션으로 AI 메시지 저장
        new_db = SessionLocal()
        try:
            ai_msg = ChatMessage(user_id=..., role="assistant", content="".join(full_response))
            new_db.add(ai_msg); new_db.commit(); new_db.refresh(ai_msg)
            yield f"data: {json.dumps({'type': 'done', 'ai_msg_id': ai_msg.id})}\n\n"
        finally:
            new_db.close()  # 반드시 닫기

    return StreamingResponse(generate(), media_type="text/event-stream")
```

**핵심 포인트**
- `generate()`는 파이썬 제너레이터. `yield`마다 SSE 이벤트 하나를 클라이언트로 보냅니다.
- SSE 형식: `"data: {JSON}\n\n"` (data: 접두사 + 이중 줄바꿈 필수)
- 스트리밍 중에는 기존 `db` 세션을 사용하면 안 되어 완료 후 `new_db`를 새로 엽니다.
- `X-Accel-Buffering: no` 헤더로 Nginx 프록시의 응답 버퍼링을 비활성화합니다.

## 6. CJK·키릴 문자 필터 — `services/groq.py`

```python
def _filter_cjk(text: str) -> str:
    cleaned = re.sub(
        r'[一-鿿㐀-䶿豈-﫿'   # 한자
        r'ぁ-ヿㇰ-ㇿ'                  # 히라가나·가타카나
        r'Ѐ-ӿ]',                             # 키릴(러시아어 등)
        ' ', text
    )
    return re.sub(r' {2,}', ' ', cleaned)  # 연속 공백 정리
    # .strip() 없음 — 스트리밍 청크의 단어 경계 공백 유지
```

- 유니코드 범위로 한자·일본어·러시아어를 공백으로 대체합니다.
- `.strip()`을 안 하는 이유: 스트리밍 청크 앞뒤 공백이 단어 경계 역할을 하기 때문입니다.

## 7. Groq 감정 분석 — `services/groq.py`

```python
def analyze_emotion(content: str) -> dict:
    response = client.chat.completions.create(
        model=MODEL_GENERAL,           # llama-3.3-70b-versatile
        messages=[
            {"role": "system", "content": "JSON 형식으로만 응답하세요..."},
            {"role": "user",   "content": content}
        ],
        temperature=0.3,
        max_tokens=100,
    )
    raw = response.choices[0].message.content.strip()
    return json.loads(raw)  # {"emotion_tags": "기쁨,설렘", "emotion_score": 4}
```

- `temperature=0.3`: 일관된 JSON 응답을 위해 낮게 설정합니다.
- `max_tokens=100`: JSON 응답만 받으므로 충분합니다.
- 실패 시 `diary.py`의 `try/except`로 감싸 일기 저장은 계속 진행합니다.

## 8. 솔루션 캐싱 — `routers/diary.py`

```python
@router.post("/{diary_id}/solution")
def get_solution(diary_id, db, current_user):
    diary = ...  # 일기 조회

    if diary.solution:        # 이미 생성된 솔루션 있으면

        raise HTTPException(400, "감정 점수 1~2점 전용")

    check_and_consume(db, current_user, "solution")  # 쿼터 소비

    solution_text = generate_solution(...)
    diary.solution = solution_text  # DB에 캐싱
```

한 번 생성된 솔루션은 `diaries.solution` 컬럼에 저장되어, 같은 일기에 다시 요청해도 AI를 재호출하지 않습니다.

## 9. 관리자 권한 의존성 — `routers/admin.py`

```python
def get_admin_user(current_user: User = Depends(get_current_user)) -> User:
    if not current_user.is_admin:
        raise HTTPException(status_code=403, detail="관리자 권한이 필요합니다")
    return current_user

@router.get("/stats")
def get_stats(db = Depends(get_db), _: User = Depends(get_admin_user)):
    ...
```

- `get_admin_user`는 `get_current_user`를 내부적으로 의존합니다. Depends 체인이 중첩됩니다.
- `_: User`로 받는 이유: 반환값을 사용하지 않지만, 권한 확인을 실행시키기 위해 선언합니다.
