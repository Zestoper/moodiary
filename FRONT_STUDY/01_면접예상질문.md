## React 기본

**Q. React에서 상태(state)를 사용하는 이유가 뭔가요?**

일반 변수는 변경해도 화면이 다시 그려지지 않습니다.
`useState`로 상태를 관리하면 값이 바뀔 때 React가 해당 컴포넌트를 자동으로 리렌더링합니다.

예: `DiaryPage`에서 `setDiaries([newDiary, ...diaries])`를 호출하면 목록이 즉시 화면에 반영됩니다.

---

**Q. `useEffect`의 의존성 배열이 뭔가요?**

```javascript
useEffect(() => { fetchHistory(); }, []);         // 마운트 시 1번만
useEffect(() => { ... }, [messages]);             // messages 바뀔 때마다
useEffect(() => { ... }, [title, content, showForm]); // 셋 중 하나 바뀌면
```

- `[]`: 컴포넌트가 처음 마운트될 때 1번 실행합니다.
- `[값]`: 해당 값이 변경될 때마다 실행합니다.
- 생략: 매 렌더링마다 실행됩니다(거의 사용 안 함).

이 프로젝트에서 `ChatPage`는 `[messages]`가 바뀔 때마다 `scrollIntoView()`를 호출해 자동 스크롤을 구현합니다.

---

**Q. `useRef`는 어디에 사용하나요?**

```javascript
const bottomRef = useRef(null);    // DOM 접근용
const recognitionRef = useRef(null); // 인스턴스 보관용
const draftTimerRef = useRef(null);  // 타이머 ID 보관용

bottomRef.current?.scrollIntoView({ behavior: 'smooth' });
recognitionRef.current?.stop();
clearTimeout(draftTimerRef.current);
```

- DOM 요소에 직접 접근할 때 사용합니다(`ref={bottomRef}`).
- 렌더링과 무관하게 값을 유지할 때 사용합니다. `useState`와 달리 변경해도 리렌더링이 발생하지 않습니다.

## Context API

**Q. React Context API를 왜 사용했나요? Props와 무엇이 다른가요?**

Props는 부모 → 자식으로만 전달할 수 있어, 여러 계층을 거치면 "Props Drilling" 문제가 발생합니다.
Context를 사용하면 어느 컴포넌트에서든 `useAuth()`로 전역 상태(user, token, login, logout)에 접근할 수 있습니다.

이 프로젝트에서 `AuthContext`는 로그인된 유저 정보와 토큰을 관리하고, `ToastContext`는 전역 알림을 관리합니다.

---

**Q. `localStorage`를 사용할 때 주의할 점은 무엇인가요?**

- **XSS 취약점**: 자바스크립트로 접근 가능해, XSS 공격 시 토큰이 탈취될 수 있습니다.
- **만료 없음**: 직접 삭제하지 않으면 영구 저장됩니다.
- **동기 API**: 큰 데이터를 저장하면 메인 스레드를 블로킹할 수 있습니다.

이 프로젝트는 JWT 토큰과 AI 페르소나 설정, 일기 초안을 localStorage에 저장합니다.

## SSE 스트리밍

**Q. SSE 스트리밍을 어떻게 구현했나요?**

```javascript
const response = await fetch('/api/chat/stream', { method: 'POST', ... });
const reader = response.body.getReader();
const decoder = new TextDecoder();
let buffer = '';

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  buffer += decoder.decode(value, { stream: true });
  const lines = buffer.split('\n');
  buffer = lines.pop(); // 불완전한 줄 보관
  for (const line of lines) {
    if (!line.startsWith('data: ')) continue;
    const data = JSON.parse(line.slice(6));
    // data.type === 'chunk' → AI 메시지에 텍스트 이어붙이기
  }
}
```

- `response.body.getReader()` — 스트리밍 응답을 청크 단위로 읽습니다.
- `TextDecoder` — `Uint8Array` 바이트 배열을 문자열로 변환합니다.
- `buffer`로 청크 경계에서 잘린 SSE 이벤트를 처리합니다.

---

**Q. SSE를 axios 대신 fetch로 구현한 이유는 무엇인가요?**

axios는 응답을 완전히 받은 후 처리하는 방식이라 스트리밍에 적합하지 않습니다.
fetch의 `response.body` (ReadableStream)를 사용하면 청크가 도착할 때마다 즉시 처리할 수 있습니다.
axios 인터셉터가 없기 때문에 토큰을 헤더에 수동으로 추가합니다.

## 낙관적 업데이트

**Q. 낙관적 업데이트(Optimistic Update)가 뭔가요? 이 프로젝트에서 어떻게 썼나요?**

서버 응답을 기다리지 않고 UI를 먼저 업데이트하는 패턴입니다.

`ChatPage`에서 메시지 전송 시:
1. 임시 ID(`temp-u-${Date.now()}`)로 유저·AI 메시지를 화면에 즉시 추가합니다.
2. AI 스트리밍이 끝나면 임시 ID를 DB에서 받은 실제 ID로 교체합니다.
3. 전송 실패 시 `filter(m => !m.id.startsWith('temp-'))`로 임시 메시지를 제거합니다.

서버 응답 대기 시간 동안 UI가 멈춰있는 느낌을 없애 UX가 향상됩니다.

## axios 인터셉터

**Q. axios 인터셉터를 왜 사용했나요?**

```javascript
instance.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

instance.interceptors.response.use(
  (res) => res,
  (err) => {
    if (err.response?.status === 401) {
      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(err);
  }
);
```

- **요청 인터셉터**: 모든 API 요청에 JWT 토큰을 자동으로 헤더에 추가합니다. 매번 수동으로 추가할 필요가 없습니다.
- **응답 인터셉터**: 401 에러 발생 시 자동으로 토큰을 삭제하고 로그인 페이지로 이동합니다.

## 그 외 기능

**Q. debounce를 어떻게 활용했나요?**

```javascript
useEffect(() => {
  if (!showForm) return;
  clearTimeout(draftTimerRef.current);
  draftTimerRef.current = setTimeout(() => {
    localStorage.setItem('diary_draft', JSON.stringify({ title, content }));
  }, 500);
  return () => clearTimeout(draftTimerRef.current);
}, [title, content, showForm]);
```

일기 내용 변경 시마다 저장하면 성능이 낭비됩니다.
타이핑을 멈춘 후 500ms가 지나야 localStorage에 초안을 저장합니다.
cleanup 함수(`return () => clearTimeout(...)`)로 이전 타이머를 항상 취소합니다.

**Q. Web Speech API로 음성 입력을 어떻게 구현했나요?**

```javascript
const recognition = new (window.SpeechRecognition || window.webkitSpeechRecognition)();
recognition.lang = 'ko-KR';
recognition.continuous = true;
recognition.onresult = (e) => {
  const transcript = e.results[e.results.length - 1][0].transcript;
  setter((prev) => prev + ' ' + transcript);
};
recognition.start();
```

- `window.SpeechRecognition` — 브라우저 내장 음성 인식 API (Chrome 권장)
- `continuous: true` — 말을 멈춰도 자동 종료 안 함
- `recognitionRef.current`로 인스턴스를 보관해 외부에서 `stop()` 호출 가능

**Q. PDF 내보내기를 라이브러리 없이 구현한 방법은요?**

```javascript
const blob = new Blob([html], { type: 'text/html; charset=utf-8' });
const blobUrl = URL.createObjectURL(blob);
const win = window.open(blobUrl, '_blank');
// HTML 내부: <script>window.onload = () => window.print()<\/script>
setTimeout(() => URL.revokeObjectURL(blobUrl), 5000);
```

- HTML 문자열로 일기 내용을 래핑한 후 `Blob`으로 변환합니다.
- `URL.createObjectURL()`로 임시 URL을 만들어 새 탭으로 열면 브라우저 인쇄 대화상자가 자동 실행됩니다.
- "PDF로 저장"을 선택하면 파일이 저장되며, 별도 라이브러리 없이 한글 폰트도 완벽 지원합니다.
