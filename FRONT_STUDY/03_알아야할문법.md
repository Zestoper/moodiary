## 1. useState

```javascript
const [messages, setMessages] = useState([]);
const [loading, setLoading] = useState(false);
const [selected, setSelected] = useState(null);

// 함수형 업데이트 (이전 상태 기반으로 변경)
setMessages((prev) => [...prev, newMessage]);
setMessages((prev) => prev.filter((m) => m.id !== deletedId));
```

- `useState(초기값)` — `[현재값, setter함수]` 반환
- `setter(새값)` — 직접 값 전달
- `setter((prev) => ...)` — 이전 상태 기반으로 새 상태 계산 (비동기 업데이트 시 안전)

## 2. useEffect

```javascript
// 마운트 시 1번
useEffect(() => { fetchHistory(); }, []);

// 의존성 변경 시
useEffect(() => {
  bottomRef.current?.scrollIntoView({ behavior: 'smooth' });
}, [messages]);

// cleanup 함수 (언마운트 또는 재실행 전 실행)
useEffect(() => {
  const timer = setTimeout(() => { ... }, 500);
  return () => clearTimeout(timer);  // cleanup
}, [title, content]);
```

- 두 번째 인자 `[]` — 마운트 시 1회
- `[의존성]` — 의존성 변경마다 실행
- `return () => {}` — 다음 실행 전 또는 언마운트 시 cleanup

## 3. useRef

```javascript
const bottomRef = useRef(null);          // DOM 참조
const recognitionRef = useRef(null);     // 인스턴스 보관
const draftTimerRef = useRef(null);      // 타이머 ID 보관

// DOM 요소에 연결
<div ref={bottomRef} />

// 사용
bottomRef.current?.scrollIntoView({ behavior: 'smooth' });
clearTimeout(draftTimerRef.current);
recognitionRef.current?.stop();
```

- `ref.current` — 참조하는 값에 접근
- `?.` (옵셔널 체이닝) — null이면 실행 안 함
- 값이 바뀌어도 리렌더링 없음 (타이머, 인스턴스 보관에 적합)

---

## 4. 옵셔널 체이닝 `?.`

```javascript
err.response?.data?.detail     // response가 null이면 undefined 반환 (에러 없음)
user?.credits                  // user가 null이면 undefined
diary?.emotion_score           // emotion_score 없으면 undefined
bottomRef.current?.scrollIntoView()  // current가 null이면 무시
```

- `a?.b` — `a`가 null/undefined이면 에러 없이 `undefined` 반환
- `a?.b?.c` — 체인으로 여러 단계 안전하게 접근
- 없으면 실행 안 해도 되는 메서드 호출에도 사용

## 5. 스프레드 연산자 `...`

```javascript
// 배열 복사 + 요소 추가
setMessages((prev) => [...prev, newMessage]);

// 배열 앞에 추가
setDiaries([newDiary, ...diaries]);

// 객체 병합 (마지막이 우선)
const updated = { ...lastMsg, content: lastMsg.content + chunk };

// 객체 스프레드로 속성 합치기
setWeatherInfo({ code, temperature: temp, ...(WMO[code] || {}) });
```

- `[...배열]` — 배열 얕은 복사
- `{...객체}` — 객체 얕은 복사
- 원본을 직접 수정하지 않고 새 배열/객체를 반환 → React 불변성 원칙 준수

## 7. async/await와 try/catch

```javascript
const handleSend = async () => {
  try {
    const response = await fetch('/api/chat/stream', { ... });
    const reader = response.body.getReader();
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      // ...
    }
  } catch {
    setMessages((prev) => prev.filter((m) => !String(m.id).startsWith('temp-')));
    addToast('전송 실패', 'error');
  } finally {
    setLoading(false);  // 성공/실패 상관없이 항상 실행
  }
};
```

- `async` 함수 안에서 `await`로 비동기 작업을 동기처럼 씁니다.
- `try`: 정상 흐름
- `catch`: 에러 발생 시 처리
- `finally`: 항상 실행 (로딩 상태 해제 등)
